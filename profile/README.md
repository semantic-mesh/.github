# Semantic Mesh

**Autonomy within domains. Explicit meaning at their boundaries.**

We are developing a domain-driven reference model for describing the meaning,
ownership and services of business domains through Semantic Domain Contracts.
The initiative is in its founding stage; its specification is not yet released.

Start in the [main repository](https://github.com/semantic-mesh/semantic-mesh)
for the concept, proposed principles, whitepaper status and roadmap.
Bring a use case, question or counterexample through
[issues](https://github.com/semantic-mesh/semantic-mesh/issues), or propose an
edit through a pull request. Read the repository's licensing status before
submitting reusable material.
