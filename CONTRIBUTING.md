# Contributing to Semantic Mesh

Start with the main repository's
[contribution guide](https://github.com/semantic-mesh/semantic-mesh/blob/main/CONTRIBUTING.md).
Repository-specific guidance takes precedence when present.
Use issues for concrete questions and proposals, and fork/branch/pull requests for
edits. Keep customer material, internal documents and credentials out of public
contributions. Check the target repository's license before submitting content.
